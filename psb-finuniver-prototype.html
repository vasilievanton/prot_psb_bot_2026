Кликабельный прототип

ПСБ × Финуниверситет · Telegram-бот и Web App · 6 октября

Это интерактивная спека для разработки. Три поверхности переключаются вверху, кнопки внутри телефона живые, а справа — заметки по логике каждого экрана.

1
Поверхности вверху: бот участника, Web App участника, Web App менеджера (отдельного бота для менеджера нет — вся его работа тоже в апке).
2
Слева — все экраны и состояния поверхности. Кликом можно прыгнуть в любое, включая «краевые» (не найден, мест нет, недостаточно баллов).
3
Справа — Dev-заметки: назначение, правила, состояния и подсказки по данным. Строго по ТЗ; открытые вопросы помечены жёлтым.
Роли: участник · менеджер · тестер · админ ~1500 студентов Валюта: баллы КВ — плейсхолдер ПСБ
